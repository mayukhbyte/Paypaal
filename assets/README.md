# Approval merchant marks

- `figma.svg` is the Figma symbol sourced from the Simple Icons repository: https://github.com/simple-icons/simple-icons/blob/develop/icons/figma.svg. It is used only to identify the named merchant in an approval card.
- The Runpod card uses the compact square icon from Runpod's official brand kit: https://www.runpod.io/brandkit. Its embedded image URL is https://cdn.prod.website-files.com/69ce570adca53340abab8376/69f0486bcca22c5af188df89_runpod-logo-square-p-2000.webp; the device could not download the source file locally.
- The supplied `Unknown Overseas Registrar` example has no named company identity. Its existing risk marker remains in place; no company logo is invented.

These marks identify merchants only and do not imply partnership or endorsement.
- Figma's official trademark guidance is at https://www.figma.com/using-the-figma-brand/; this icon is used only to identify the merchant and does not imply endorsement.
